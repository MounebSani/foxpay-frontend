🦊 FoxPay
Tagline: Sharp Payments. Fast Life.
📌 Overview
FoxPay is a modern fintech frontend application designed for digital wallet services, including airtime, data, bill payments, money transfers, and transaction management.
It provides a clean, responsive, and mobile-first UI built using HTML, CSS, and JavaScript.
🚀 Features (Frontend MVP)
🔐 Login & Registration UI
📊 Dashboard with wallet overview
💰 Wallet interface (virtual card design)
📱 Airtime purchase UI
🌐 Data bundle purchase UI
🔁 Money transfer UI
⚡ Bills payment UI
📄 Transaction history page
👤 User profile page
🎁 Referral page
🔔 Notification system UI
📱 Mobile responsive layout
